# Thumbnail prompts for 30 new styles

One prompt per new style. Every prompt uses the same subject and setting so the new thumbnails read as one set: the only thing that changes between them is the style.

## The shared subject

> a ten-year-old boy explorer with short curly black hair and warm brown skin, wearing a teal jacket with brass buttons and a small leather satchel, holding up a glowing brass lantern, in a moonlit garden with stone arches and flowers

To use a different subject, find and replace this sentence in every prompt below.

## How to generate them

1. Generate each image **square (1:1), at 1024 × 1024 or larger**.
2. Keep the boy **waist-up and centered**, so he sits in the same spot as the existing thumbnails.
3. For the most consistent boy, generate prompt 1 first, pick the best result, then attach it as a reference for the rest. Leave it out for prompts where the material changes him completely (Hologram, Marble Statue, Toy Brick Build), where it can fight the style.
4. Save each image with its slot number, e.g. `42-crayon.png`, and send them back. They'll be fitted into the thumbnail grid in this order.
