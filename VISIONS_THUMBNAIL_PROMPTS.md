# Thumbnail prompts for the 16 Ether Visions

These prompts make preview thumbnails for the **Visions** tab (`visions-data.js`, ids v1–v16). Right now those tiles show dark gold gradients.

Each prompt shows a different subject, so the tab reads as a varied set while staying true to each look.

## How to generate them

1. Generate each image **square (1:1), at 1024 × 1024 or larger**.
2. Keep the main subject **centered**, with some breathing room at the edges, so every tile crops cleanly.
3. Don't attach a reference image.
4. Save each image with its id, e.g. `v01-kemet-starpilot.png`, and send them back. They'll be packed into one exact grid atlas (4 columns × 4 rows, no gutters) at `assets/thumbnails/visions-01.webp`.
