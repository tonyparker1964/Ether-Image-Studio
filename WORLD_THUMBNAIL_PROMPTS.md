# Thumbnail prompts for the 15 world anime looks

These prompts make preview thumbnails for the **World anime** tab (`world-anime-data.js`, ids w1–w15). Right now those tiles show colored gradients.

Unlike the older style thumbnails, which all show the same boy, **each prompt here has a different character**. The world tab is about variety, so the thumbnails show it: different ages, heritages, builds and outfits, each matched to its region.

## How to generate them

1. Generate each image **square (1:1), at 1024 × 1024 or larger**.
2. Keep the character **waist-up and centered**, so every tile crops the same way.
3. Don't attach a reference image. Each character is meant to be new.
4. Save each image with its id, e.g. `w01-manhwa.png`, and send them back. They'll be packed into one exact grid atlas (5 columns × 3 rows, no gutters) at `assets/thumbnails/world-01.webp`.
